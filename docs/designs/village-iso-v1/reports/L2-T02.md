## Spécification pour artist : `compose(stem, out, socle_shadow=True)`
Lecture de `cls` (déjà ouvert, `codes[i][2]` est B) :
- `socle_shadow=True` : comportement actuel, rien ne change.
- `False` : un pixel avec B dans 32..160 (c'est 64, jamais >= 128, le seuil du masque de toit à 255) n'est jamais `occluded` : il garde le ton de son n.L (`tone`). Dans `.classes.png`, B (le drapeau d'ombre) est mis à 0 sur ces pixels, pour que l'audit A reste d'accord avec l'image donnée à FLUX.
- Condition à ajouter dans la boucle : `and not (not socle_shadow and 32 <= codes[i][2] <= 160)`. `compose` ne doit pas lire B autrement (R et G restent snappés comme aujourd'hui). `iso_loop.py prep-blockout` passe `False`, rien d'autre.
- Bord : la passe est à 1 échantillon, non filtrée, le 64 est donc net. Sur le contour socle/mur, un pixel de mur peut rester ombré, c'est voulu (seul le dessus est marqué).

## Limites
- Les autres surfaces basses (plancher de la tente grand, pavés, champ, gradins) ne sont pas marquées (cf. L1-T18, clé `"sol"` possible).
- `stage_exports.passes_stem` lit toujours le `.cls.png` du cache par son nom, inchangé.
