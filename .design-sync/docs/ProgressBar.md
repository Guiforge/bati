# ProgressBar

`progress` runs from 0 to 100 (unlike `InkGauge`, which takes 0..1). A thin progress line for a session's advance (braise, the default) or an oath or tier towards a goal (gold on `#362C15`). Use `InkGauge` instead when the bar carries a figure or is the screen's hero; a card never shows two bars.
