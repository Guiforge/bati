# L4-T08b : maquettes de 3 petits animaux (chat, poule, corbeau)

Statut proposé : prêt pour revue
Auteur : blender
Tour de revue : 1

## Fait
- `scripts/iso/blockouts/gen_animaux.py` : générateur sur le modèle de `gen_decor.py` (helpers copiés, ce module écrit ses fichiers à l'import). Contrôle de chaque pose : dans la case, au sol, hauteur dans une fourchette ; sort 1 sans rien écrire sinon.
- `scripts/iso/blockouts/pieces/animal_{chat,poule,corbeau}_{repos,a,b}.json` : 9 poses, canevas `villager`, `light` de face, `lineScale` 0.3 (un villageois : 0.5).
- `scripts/iso/blockouts/render_animaux.py` : rend les 9 poses par `stage_exports.export` (rendu, masques, ancrage, ombre, volumes, points d'accroche, masque émissif et de toit), puis monte la planche. Les maquettes webp du lot 1 vont dans `renders/animaux-maquettes/`, pas dans `assets/`.
- Sorties : `scripts/iso/blockouts/renders/pieces/animal_*` (les 9 jeux de fichiers `.rgba/.png/.dark/.green/.mask/.classes/.emissive/.roof.png` + `.anchor.json`).
- Planche de contrôle : `scripts/iso/blockouts/renders/animaux_planche.png` (1320 x 1880) : en haut une case (losange 768 x 384 px), le fermier et les 3 animaux au repos ; dessous, chaque animal, ses 3 poses, à 2x.
- `scripts/iso/blockouts/VERSIONS.md` : une entrée L4-T08b.

Poses (cycle 8 i/s : repos, a, b, a) : chat assis / pas / pas contraire (paires de pattes inversées) ; poule debout / penchée / bec au sol ; corbeau ailes pliées / ailes levées / ailes écartées bas.

- Ombres : 11 polygones (chat, poule) ou 13 (corbeau) par pose, un par primitive ; pas de flaques (aucune partie émissive) ; `pointsAccroche` présent (`px`, `grid`) mais vide de sens : pas de toit, pas de porte.
- Coût FLUX : 0 (aucun appel).

## Douteux ou non fait
- `scripts/iso/g0.py` non relancé : il vérifie le POC, pas ces pièces ; le losange 2:1 et la couleur composée viennent du même moteur et des mêmes passes que les villageois, sans vérification propre. Sens de la lumière : même `light` que les villageois, vu sur la planche (face éclairée à gauche).
- Maquettes de forme seulement : corps en troncs de cône, très anguleux (le chat est un bloc avec deux oreilles, la queue de la poule un cône). À 30 px de haut à l'écran, la silhouette tient ; la peinture (plus tard) devra reprendre les formes. Le corbeau a une seule patte visible, ses ailes sont des bâtons.
- Pas de planche à 8 i/s montée ni de GIF : seulement les 9 poses.
- Règle d'écart des ombres sur la carte : non vérifiée (aucune pose n'est posée sur la carte).
- Un nom de matériau n'a pas de couleur d'animal : chat `stone`, poule `plaster` (+ queue `darkwood`, crête `tile`), corbeau `iron`. À revoir à la peinture.

## Pour la suite
- Hauteur de chaque animal en cases (z, repos / pose la plus haute) : chat 0.135 / 0.156 ; poule 0.130 / 0.167 ; corbeau 0.117 / 0.169 (ailes levées). Un villageois 0.49 : 0.24 à 0.34 de lui.
- Sprite : canevas `villager` 768 x 768 px, pxScale 2, ancrage `[384, 704]` = centre de la case au sol. Les 3 poses d'un animal ont la même taille et le même ancrage : empiler tel quel pour la planche. Le contenu occupe au plus ~145 x 105 px de ce canevas (le reste est transparent) : un recadrage serré par animal (taille fixe pour les 3 poses) réduirait le poids et le décodage, avec l'ancrage décalé du même recadrage.
- Ils regardent à droite de l'écran (+gx -gy) ; l'app les retourne pour l'autre sens, comme les villageois (CHECKLIST 15, lumière de face). Ils sont posés au centre de la case : l'ancrage est le centre, pas un coin.
- Ombre au sol : `anchor.json` `shadow[].px` (relatif à l'ancrage) sous la lune, comme les bâtiments ; pour un animal qui bouge, utiliser l'ombre de la pose en cours ou celle du repos pour toutes (écart de quelques px). `noShadow` n'est posé sur aucune partie.
- Ce qui bouge (ailes, pattes) est dans le blockout de l'animal lui-même : pas d'axe séparé, car l'animal entier est le sprite animé.
- Rejouer : `python3 scripts/iso/blockouts/gen_animaux.py` puis `scripts/iso/team/heavy.sh python3 scripts/iso/blockouts/render_animaux.py render [corbeau_a ...]` ; `sheet` seul refait la planche sans Blender.
