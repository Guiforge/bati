## 📋 GENERATION CHECKLIST

### For Each Asset

- [ ] **Format**: 16:9 aspect ratio (1920x1080 or 2560x1440)
- [ ] **Style**: Franco-Belgian Comic Book (thick outlines, cel-shaded)
- [ ] **Palette**: Dark (#0B0F19 base) with vibrant accents
- [ ] **Content**: Environment only, NO characters
- [ ] **Mood**: Matches quest/adventure theme
- [ ] **Composition**: Cinematic, dramatic angles
- [ ] **Lighting**: High contrast, dramatic (torch/magic/sun/moon)
- [ ] **Quality**: High resolution, crisp lines, polished finish

### Midjourney Parameters

```
--ar 16:9 --style raw --stylize 150 --v 6
```

## 🎨 COLOR REFERENCE (For All Images)

**Primary Palette**:

- **Background Base**: `#0B0F19` (Deep Obsidian Blue)
- **Primary Accent**: `#0D33F2` (Electric Blue)
- **Secondary Accents**:
  - Fire/Forge: `#FF6B35` (Vibrant Orange)
  - Nature/Druid: `#5FD35F` (Emerald Green)
  - Magic/Arcane: `#A855F7` (Mystic Purple)
  - Shadow/Dark: `#2D1B4E` (Dark Purple)
  - Holy/Divine: `#FFD700` (Golden)

**Rendering Style**:

- Thick black outlines (comic book ink)
- Cel-shading (flat color areas with hard shadow edges)
- High contrast lighting
- Glowing effects on magical elements
- Motion blur for action
- Particle effects (embers, mist, sparkles)
