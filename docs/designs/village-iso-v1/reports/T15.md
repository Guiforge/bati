# T15 : Ambiance jour

## Quoi
- Choix de la lumière par canal et heure : `choisirLumiere({jourSeul, plus, heure, force})` (components/village/iso/lumiere.ts). `JOUR_SEUL = DISTRIBUTION === "play"` dans src/distribution.ts. Gratuit Play = jour fixe ; F-Droid et GitHub = jour de 7 h à 20 h, nuit sinon ; `plus` vaut false (shortcut : Bati+ n'existe pas encore).
- Jour : lavis chaud (#F2E2B4, 50 %) sous tout ce qui se dresse : herbe, routes, ruisseau, eau de l'île (un Path par tuile, derrière les sprites) ; plancher de forêt et mer du monde (Monde.tsx), les arbres restent opaques parce que le lavis est posé avant leurs tuiles. Voile de bords chaud. Fenêtres, flammes, veilleuses et lucioles éteintes (`vieDe("jour")`).
- Essai du calque sur les sprites (tours 1 et 2) abandonné : un sprite de nuit teinté se lit comme un fantôme beige. Code retiré.
- Branchement : VillageScene calcule la lumière derrière INTEGRATION (éteint : nuit) et la passe à IsoVillage (`lumiere`). `bati://dev-iso?ambiance=jour|nuit` pour qa (défaut nuit).
- Étiquettes : les textes de l'onglet (IsoVillage, `bgDark`) sont sur leur propre fond clair, identique jour et nuit ; aucune étiquette ne pose sur le sol, rien à recalculer. Contraste non mesuré.
