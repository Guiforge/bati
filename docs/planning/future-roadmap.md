# Future Roadmap

> Speculative ideas only. This file is a parking lot, not an execution plan.
> If priorities conflict with [roadmap-alignment.md](roadmap-alignment.md), the alignment roadmap wins.

## How to use this page

Use this page to store ideas that are intentionally **not in current MVP execution**.
Move an item to [roadmap-alignment.md](roadmap-alignment.md) only when:

- It has clear user value,
- It does not degrade core workout clarity/efficiency,
- It has an owner and acceptance criteria.

## 2) Device and context expansion

## 3) Progression depth

- Cosmetic customization loops

## 4) Coaching intelligence

- Smarter adaptive planning

## 5) Platform quality and operations

- Performance hardening
- Accessibility upgrades beyond baseline AA
- Release/distribution automation

## Triage checklist for promotion to active roadmap

- [ ] User problem is concrete and validated.
- [ ] Scope is small enough for incremental delivery.
- [ ] No regression risk to core workout loop.
- [ ] UX copy and visual hierarchy remain clear.
- [ ] Acceptance criteria are testable.
