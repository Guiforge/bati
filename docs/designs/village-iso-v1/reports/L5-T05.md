## Douteux ou non fait
- Les lucioles s'allument et s'éteignent ensemble (un seul nœud) ; un nœud par luciole dépasserait le plafond. Marqué `shortcut` dans le code.
- Le battement des corbeaux est un écrasement vertical du vol entier, pas deux formes ; à juger sur appareil.
- La graine est celle de la vague (`GRAINE_VIVANT` + `n`), pas du jour : deux ouvertures de l'app rejouent les mêmes vagues dans le même ordre. Un seed par jour demanderait de passer le jour en prop.
- Lisibilité du corbeau noir sur le ciel `isoSkyTop` à `bgDark` : le liseré froid doit suffire, non vu à l'écran. Le rat (gris foncé sur herbe sombre) idem.
- Le rat est caché derrière la ferme/le mannequin/la grange par l'ordre de profondeur seulement si leurs sprites recouvrent sa course à l'écran ; non vérifié sur capture. Le rat n'est pas dans `carte.vues` des marcheurs (leur planification) : un marcheur peut le croiser visuellement.
- Les 5 suites tombées sous charge n'ont pas été relancées toutes ensemble une seconde fois.
