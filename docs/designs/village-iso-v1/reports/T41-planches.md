# T41 point 1: planches des stades

Une planche par bâtiment, rough | solid | grand, à l'échelle 0,5 commune (tous les bâtiments partagent le pixel de grille). Nuit seulement : `lumiere.ts` ne teinte pas les sprites, le jour n'est qu'un lavis sous le terrain (T15). Un stade non peint montre sa maquette, légendée. Script : `scripts/iso/t41_stades.py`.

**Planche « croissance du village » (paliers 1, 6, 12) : non produite.** Le rendu de la carte et dev-iso ne se capturent que sur l'appareil ; pas d'émulateur dans cette préparation.
