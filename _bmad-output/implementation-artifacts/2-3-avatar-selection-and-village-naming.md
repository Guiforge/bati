# Story 2.3: Avatar Selection and Village Naming

## User Story
As a **new user**, I want **to choose my avatar and name my village**, So that **I feel ownership and connection to my fitness journey**.

## Acceptance Criteria
✅ 6 avatar options displayed (Warrior, Mage, Rogue, Paladin, Ranger, Berserker)
✅ Each avatar has description explaining theme
✅ Tapping avatar selects with visual feedback
✅ Village naming screen appears after selection
✅ Text input accepts village name (max 20 characters)
✅ Village name validated (no special characters, not empty)
✅ "Create Village" button saves selection
✅ User profile created in database
✅ User redirected to home after creation
✅ Onboarding marked complete
