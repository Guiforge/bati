# Features Overview

## Content & progression

- **Quests**: workout templates (rounds + exercises + targets)
- **Completed sessions**: history of what you trained, including duration and XP
- **Adventures**: multi-step campaigns that chain multiple quests
- **Boss adventures**: campaigns marked with `kind = "boss"`

## Browsing & discovery

- Quest browsing with filters (muscles, equipment)
- Adventures gallery (multi-step only)
- “Continue adventure” shortcut on Home when a run is active

## Localization (i18n)

- UI strings are localized via i18next (`locales/en.json`, `locales/fr.json`)
- Content is stored with both EN/FR fields in the DB (titles/descriptions)

## Dev tools

In development builds, a **Dev Tools** screen is available (for example: resetting the local database).
