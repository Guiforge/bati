# Modèle de rapport de tâche (`reports/<id>.md`)

```
# <id> : <objectif>

Statut proposé : prêt pour revue | bloqué (raison)
Auteur : blender | artist | engineer | qa
Tour de revue : 1 | 2 | 3

## Fait
- ce qui a changé, fichier par fichier

## Preuves
- commandes lancées et leur résultat (copié, pas résumé)
- chemins des planches, captures, mesures, verdicts d'audit (A)
- coût FLUX de la tâche (réel, par le champ `cost`)

## Douteux ou non fait
- ce qui n'est pas vérifié, et pourquoi

## Pour la suite
- ce qu'un autre coéquipier doit savoir (chemins, ancrages, mesures)
```
