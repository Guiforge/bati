# Modèle de carte de tâche

```
Id : L<lot>-T<numéro>
Objectif : une phrase, le résultat attendu
Propriétaire : blender | artist | engineer | qa
Entrées : fichiers, mesures, images dont la tâche part
Fichiers autorisés : la liste exacte (rien d'autre n'est écrit)
Contraintes : règles du prompt et décisions qui s'appliquent (DECISIONS.md, lignes citées)
Acceptation : items de CHECKLIST.md, tests, mesures, captures attendues
Revue : iso-code-reviewer | iso-art-reviewer | iso-design-reviewer | qa
Budget FLUX : 0 $ ou montant maximal
Dépend de : ids
Taille : une demi-journée d'agent au plus, sinon découper
```
