## Fait
- `constants/isoSpec.json`, dans `canvases`, quatre lignes après `building2x2` :
  ```
  "building2x3": { "w": 1280, "h": 1280, "footprint": [2, 3], "anchor": "footprintBottom" },
  "building3x3": { "w": 1280, "h": 1600, "footprint": [3, 3], "anchor": "footprintBottom" },
  "building1x2": { "w": 896, "h": 1152, "footprint": [1, 2], "anchor": "footprintBottom" },
  "building1x3": { "w": 1280, "h": 1216, "footprint": [1, 3], "anchor": "footprintBottom" },
  ```
- **Largeur** (même règle que les canevas existants) : `iso_blockout.py` pose le coin bas de l'emprise (fw, fh) en (w / 2, h - 64). Les coins latéraux sont à fh * 192 et fw * 192 px de lui, d'où w = 2 * (max(fw, fh) * 192 + 64). Cela donne 896 pour 2 × 2 (existant), 512 pour 1 × 1 (existant), 1280 pour 2 × 3 (valeur de `blender`, gardée), 896 pour 1 × 2, et 1280 pour 1 × 3 et 3 × 3.
- **Hauteur** : hauteur libre au-dessus du coin du fond (0, 0) = h - 64 - (fw + fh) * 96 px. Une unité de hauteur vaut 271,529 * sin 60° = 235,15 px. Marge = hauteur libre - hauteurMax du stade le plus haut de l'emprise (`heights.json`).
  - Marges existantes : `tower1x1` 1024 - 3,5 (wizard_tower) * 235,15 = **201 px** (0,85 unité), la plus serrée ; `building2x2` 896 - 2,88 (windmill) * 235,15 = 219 px. Règle retenue : marge d'au moins 200 px, h arrondi au multiple de 64 au-dessus.
  - 1 × 2, high_road 2,3 : 64 + 288 + 540,8 + 200 = 1092,8, donc h = 1152, marge 259 px (1,10 unité).
  - 1 × 3, castle_wall 2,3 : 64 + 384 + 540,8 + 200 = 1188,8, donc h = 1216, marge 227 px (0,97 unité).
  - 3 × 3, heroes_hall 3,0 : 64 + 576 + 705,5 + 200 = 1545,5, donc h = 1600, marge 254 px (1,08 unité).
  - 2 × 3, barn 1,9 : h = 1280 de `blender`, marge 289 px (1,23 unité). Gardé, puisqu'il dépasse déjà la règle.
- `__tests__/iso-spec.test.ts` : la liste `shortcut:` est retirée. Le test vérifie deux choses :
  - la règle de largeur pour chaque canevas `footprintBottom` ;
  - pour chaque bâtiment de `batiments`, un canevas de même emprise dont la marge au-dessus du stade le plus haut (lu dans `heights.json`) atteint au moins 200 px.

  Un bâtiment sans canevas, ou sans hauteur dans `heights.json`, rend le test rouge.
- `components/village/iso/isoSpec.ts` est inchangé. Le type `PointsAccroche` n'est pas touché.
