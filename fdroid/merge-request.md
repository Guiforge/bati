---

**Bati** is an offline-first fitness RPG: workouts are quests, reps land as damage on a boss, and a
village grows out of which muscles you actually trained. It makes **no network requests at all** —
no account, no server, no analytics, no ads. Everything lives in a local SQLite database.

* Source: <https://github.com/Guiforge/bati> — MIT
* Artwork: CC BY-SA 4.0, generated with FLUX.2 through our own Black Forest Labs API account.
  [`scripts/provenance.json`](https://github.com/Guiforge/bati/blob/main/scripts/provenance.json)
  records the model, exact prompt and seed for all 134 images, so any of them can be reproduced.
* 11 Android permissions, none dangerous. No Firebase, no Play Services, no install referrer.

### Notes on the recipe

It is an Expo / React Native app, so several flags are unusual and deliberate (short form in the
metadata's `MaintainerNotes`):

* **No `subdir`, and `build:` instead of `gradle:`.** `android/` is generated by `expo prebuild`
  and is not in the checkout. fdroidserver validates `subdir` *before* running `init:`, so any
  `subdir` pointing into it aborts the build before a command runs.
* **No prebuilt binaries.** Expo SDK 57 ships 22 native modules as precompiled `.aar` files in
  bundled `local-maven-repo` directories. `package.json` sets
  `expo.autolinking.buildFromSource: [".*"]` so Gradle compiles every module from source
  (subprojects go from ~20 to 42), and `init:` deletes every `local-maven-repo` explicitly —
  the same switch `templates/build-react-native.yml` recommends.
* **`scanignore: node_modules`, not `scandelete`.** With `scandelete` the scanner deleted the
  whole `build.gradle` of `react-native-safe-area-context` and `masked-view` over a local
  `maven { url … }` line, and the build then failed with "No variants exist". Nothing is hidden:
  the prebuilt binaries are removed explicitly in `init:`, and there is no proprietary dependency
  left to find.
* **`init:` removes the `expo-dev-*` packages.** They are devDependencies, but `npm ci` installs
  them and autolinking compiles them in. `npm ci --omit=dev` is not an option — `babel-preset-expo`
  lives there too and Metro needs it to bundle.
* **No Firebase.** `expo-notifications` was the only thing pulling `firebase-messaging`; it was
  removed from the app entirely, which also took it from 33 Android permissions to 11.

`fdroid build com.guiforge.bati:10201` succeeds locally: 90 MB, 11 permissions, zero
`com.google.firebase` entries in the APK.
