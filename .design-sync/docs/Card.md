# Card

A panel, not a shadow: `$surface` fill, 1 px `$borderStrong` frame, radius `$3`, padding `$4`, no drop shadow. The one hero card of a screen (Home's quest stage, the Victory card) takes `borderWidth={1.5}`. With `onPress` it becomes a button and presses down slightly. Accepts any YStack prop for layout (`gap`, `p`).
