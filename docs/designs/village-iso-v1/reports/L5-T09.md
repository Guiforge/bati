# L5-T09 : reflets d'eau regroupés

## Quoi
Un `Animated.View` par reflet (18 cases) devient 5 couches animées, une par délai (`delaiReflet` donne 5 valeurs : 0, 0.25, 0.5, 0.75, 1). Course et opacité ne dépendent que du délai, donc les cases d'un même délai partagent la couche (translation + opacité) ; chaque reflet est une `View` statique, inclinée une fois (`-26.57deg`). Même courbe `reflet()`, mêmes valeurs. Un seul nœud était impossible : 5 délais différents.

Profondeur : les reflets ne peuvent pas rester entre les images d'eau et les bâtiments avec un seul nœud par délai. Les 5 couches sont montées juste après la dernière image d'eau (`refletsPar`, dans `IsoCarteDemo.tsx`), donc après tous les canaux. Un reflet est donc dessiné par-dessus un bâtiment placé plus tard dans l'ordre s'ils se recouvrent. La case juste avant un pont (2-9) perd son reflet, puisque le tablier le couvrait (seul recouvrement réel connu). Rien n'est animé sans horloge (inchangé).
