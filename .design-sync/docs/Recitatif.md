# Recitatif

The BD caption box: a title set over art in a rectangular ink cartouche (`$bgDark` fill, 1 px `$borderStrong`, radius `$1`, Alegreya 700 in bone). Pin it to the bottom-left edge of an illustration: quest and adventure cards, the exercise art, the Victory plate, session details.

- It names a thing in the world (a quest, an adventure, a boss). Never a sentence, never a number on its own.
- A kicker above it (`QUEST COMPLETE!`, a date) is Noto Sans 700, tracked 2, gold for an achievement.
- `numberOfLines={2}` for long titles.
