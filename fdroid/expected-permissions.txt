# Every permission the built APK is allowed to carry, one per line, sorted.
#
# This is the only list that describes the *shipped* artefact. `__tests__/android-permissions.test.ts`
# runs on every push and is the fast pre-check, but it scans npm package manifests, and a Gradle
# AAR is not one: WAKE_LOCK and FOREGROUND_SERVICE reached every release for months without ever
# appearing in a list, because androidx.work declares them and nothing in node_modules does.
# The release workflow diffs this file against `aapt2 dump permissions` on the real APK.
#
# Adding a line here is a decision about what the install screen, Exodus Privacy and an F-Droid
# reviewer will see. Write the justification in ALLOWED in that test file at the same time — a
# permission listed here and nowhere else has a gate but no reason.
#
# Blank lines and lines starting with # are ignored by the gate.

android.permission.ACCESS_FINE_LOCATION
android.permission.FOREGROUND_SERVICE
android.permission.FOREGROUND_SERVICE_LOCATION
android.permission.INTERNET
