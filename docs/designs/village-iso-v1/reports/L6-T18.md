# L6-T18 : village qui pousse, premier pas

Engineer, 30/10. Aucun bâtiment déplacé, `isoLayout.json` inchangé, aucune image, aucun nœud animé.

## Fait
1. **Damier caché** : `IsoCarteDemo.tsx` (Tuile) dessine la terre en une base verte unie (trait de même couleur qui cache les coutures) puis des plaques de variantes en formes organiques (`solOrganique.ts` `blob`, courbe quadratique, rayon qui ondule, plaques qui se recouvrent). Eau et pont restent en losanges (canal droit, voulu). La grille reste interne.
2. **Rues** : `rues.ts` (pur) + `RuesDessinees.tsx`. Bande au trait d'encre, nœuds de case décalés de 0,14 case, arêtes courbées. Rang par distance de Chebyshev au feu de camp : terre (<=7+), empierrée (<=7, pointillé de pierres), pavée (<=3, joints) ; largeurs 0,5 / 0,72 / 0,94 case ; place pavée en blob autour du feu. Version ombrée dans le clip des ombres. Couleurs : `isoRueEmpierree`, `isoRuePave`, `isoRuePaveJoint` dans rawColors, branchées par `biomes.defaut.sol` (`rueEmpierree`, `ruePave`, `ruePaveJoint`, `lisiere`).
3. **Portes** : un sentier par bâtiment (sauf le feu de camp, sur le carrefour), du point `porte` de son stade peint (solid, grand, rough), ramené sur l'emprise, jusqu'au nœud de rue le plus proche. Le test vérifie porte sur l'emprise, fin sur une case de chemin, moins de 3 cases.
4. **Bord** : bord de l'île en blobs (base, ombre, crépuscule), halo `isoForetSol` à 60 % sous le bord pour fondre dans la forêt ; `monde.ts` élargit la clairière de 0 à 120 % selon un bruit (jamais sous 80 dp). Densité de décalques `densite()` : 1 au centre, 0,35 au bord ; le bonus « rive » est retiré, il reste celui du bord de chemin.

## Contraintes
- Chaque case garde son palier ; tap au masque, nœuds animés (64/48), ombres : non touchés. Même arbre de nœuds SVG à tous les paliers (test `iso-sol-rendu` vert).
- Mémoire bitmap : mêmes tuiles Svg qu'avant (1024 px au plus), aucune surface ajoutée ; coût en chaînes `d` seulement (environ 50 Path par tuile contre environ 40).
- Pas de useMemo/useCallback, aucune dépendance.
