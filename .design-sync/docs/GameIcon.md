# GameIcon

Inked glyphs from game-icons.net, tinted with `color`: castle, flame, sword, scroll, shield, trophy, coins, crown, muscle, lightning, heart, star, wood, stone, fire, water, wind, grain, chest, gold. Optional framed form with `bgColor` and `shape` (`rounded`, `circle`, `square`) and a small `badge`. Bati uses these instead of emoji. Colour by role: gold `#E2B54A` for rewards, braise `#F08A4B` for action and danger, ash `#A89C88` for metadata, bone `#ECE4D4` for neutral.
