# Audit: sharing, 2026-10-01

> Worktree `share`, 8 shots taken by hand on the emulator (seeded year of history plus one seeded
> outing, map tiles switched on): the recap header, the share screen for an outing and for a
> workout, the Android share sheet, the journal list and session page, the new-quest editor with
> import, a hero quest with its share button. The five personas of the protocol, run in parallel
> on the same shots. The trigger was a hero's report: the share button was hard to find, and an
> accepted map never showed in the journal's previews.

## Second round: bugs, performance, QA

Three reviewers in parallel on the finished change, then a senior audit of the uuid work. What
they found and what became of it:

| Finding | Outcome |
|---|---|
| `transactionOrFallback` was never atomic on a phone: Drizzle's expo driver sends COMMIT at the callback's first `await`. Every multi-row save (a session, boss damage, an oath, an import) was written row by row. | **Fixed at the root**, `db/client.ts`: the native `withTransactionAsync`, which waits for the callback. `setQuestExercises` goes through the same queue. `db-transaction.test.ts` holds it against Drizzle's real behaviour. |
| Device sync matched two different hero quests by title (an outing filed as a quest on each phone copies the same seed title). | **Fixed**: hero rows match by uuid (0066); the name only speaks for a row with no uuid, and the named side's uuid is adopted. |
| The picture could be captured before its map arrived, under a map credit. | **Fixed**: `TraceThumb` reports the map's state, Send waits for it, the credit only shows over a displayed map, and the share card's snapshot jumps the queue. |
| Map snapshots queued for rows already scrolled away; `exists` checks on every render; old-style pictures kept forever. | **Fixed** in `src/gps/mapThumb.ts`: released rows fetch nothing, the folder is read once, other versions are deleted. No size cap yet (`ponytail:`). |
| A run under 400 m drew an empty square once its ends were cut. | **Fixed**: it shares as a workout does, with its painting. The ends are now cut on every shared picture, map or not. |
| GPX did nothing when the phone has no share sheet; double taps sent twice; caches refilled from a rolled-back write. | **Fixed.** The GPX case has a test; the double-tap guard (a ref) and the invalidation after a rollback are code only. |
| A write from outside the queue that lands during an open transaction is rolled back with it. | **Kept**, written down in `db/client.ts`: rare (a rollback is a failed save), and the exclusive connection that avoids it needs every write inside a transaction to go through `tx`. |

## Third round: a quest file from a stranger, 2026-10-02

The hero asked two things of the quest import: that a cheater's file could not break the app or
pay more than a quest written by hand, and that someone non-technical could receive a quest
without knowing what a JSON file is. Three adversarial audits ran on the import and its fixes,
plus a release build on the emulator opening a hand-made hostile file from Files.

| Finding | Outcome |
|---|---|
| An image named `constructor` or `__proto__` resolved to `Object.prototype` in the asset maps, which expo-image then hands to native. | **Fixed at the root**: every getter in `constants/assetMap.ts` goes through `lookup()`, own keys only. |
| A 400 KB PNG can be a 16000 px square, a gigabyte decoded on every screen that draws it. | **Fixed**: `imageSize` reads PNG, JPEG and WebP headers; a carried picture over 1024 px a side is dropped for the placeholder. |
| Bidi overrides, zero-width spaces and controls in titles; blank titles and names; 2000-character titles. | **Fixed**: stripped, refused when blank, cut at 120 by code point. |
| A muscle or pattern a newer version adds made every file it sends "not a quest" on older phones. | **Fixed**: labels degrade (dropped, or no pattern); a code that changes what a set is worth says "update". |
| A borrowed uuid silently overwrote the hero's own quest. | **Fixed**: the preview says so and offers "Keep both". |
| The preview showed "1000000 rounds" and a hundred-digit target from a hand-made file (seen on the emulator). | **Fixed**: numbers are held to the editors' ranges when the file is read, not only when it is written. |
| Opening the file from Files said "unreadable" on the emulator: Expo Router decoded the URI in the route, and Android only grants the exact URI it sent. | **Fixed**: the URI never enters the route (`src/incomingFile.ts`). The audit found the same bug in the picker door, a regression from 2.7.0. |
| A friend's quest is often why Bati gets installed, and onboarding swallowed the file. | **Fixed**: the preview opens before onboarding. |
| `file:///dev/zero` through a VIEW intent would read forever. | **Fixed**: only `content://` is read. |
| An imported movement named "Outrider's Ride" got the mounted speed cap. | **Fixed**: `isMountedOuting` checks the seed creator. No reward was at stake. |
| Wi-Fi QR transfer between two phones. | **Not done**: a local server is a third network module and a privacy policy change; Quick Share already carries the file. |
| A `.bati` extension. | **Not done**: chat apps type a file by extension, and `.bati` arrives as `application/octet-stream`, which only a filter claiming every unknown file could catch. Tapping the `.json` opens Bati. |
