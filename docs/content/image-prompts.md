## 📝 Generation Notes

### Batch Processing

1. Copy each prompt individually into Midjourney
2. Add the appropriate `--ar` parameter for landscapes (16:9)
3. Use consistent `--style raw --stylize 150 --v 6` across all
4. Generate 4 variations per prompt, select best
5. Upscale selected variations to maximum resolution

### Quality Control

- Ensure all images use **thick black outlines** (comic book style)
- Verify **dark backgrounds** (`#0B0F19` or close)
- Check **glowing effects** are present on characters
- Confirm **cel-shaded rendering** (flat colors with hard shadows)
- NO CHARACTERS in environment shots (quests/adventures)

### File Naming

- Use exact filenames as specified (snake_case)
- PNG for characters (exercises, bosses)
- JPG for environments (quests, adventures)
- Save at high resolution (2560x1440 for 16:9, 1024x1024 for square)
