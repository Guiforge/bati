# L4-T05 - accessibilité de la carte (code)

## Avant / après (TalkBack, un bâtiment)
- Avant : la carte lisait « Forge, stade : solide » (bouton, action « Ouvrir le détail »), puis la liste du Village lisait la même forge avec « rang N ». Deux arrêts par bâtiment, deux mots différents.
- Après : la carte est muette (`importantForAccessibility="no-hide-descendants"` + `accessibilityElementsHidden` sur `iso-village`). Un seul arrêt, dans la liste, avec son vocabulaire (`village.building_rank`, « rang N »).

## Choix
La liste reste la porte : elle existe drapeau éteint, ouvre déjà la fiche via `openBuilding`, et c'est la seule source du mot « rang ». La couche accessible de la carte (`iso-acces`, `iso-batiment-*`) est supprimée, pas seulement masquée : une vue masquée serait du code mort. Les clés `village.iso.*` (building, open, stage_*) n'ont plus de lecteur, retirées des 5 langues. Prop `nom` retirée d'IsoVillage et de VillageScene.
