# Settings (`/settings`)

## Purpose

Settings is where you personalize the experience.

## Main features on this page

- **Language preference**: switch between English and French.
- **User preferences**: adjust the way the app feels for you.

## Visual rules

- Settings rows should feel like a tidy preference panel.
- The avatar picker should stay readable and predictable.
- Secondary values should support, not compete with, the labels.

## Typical user actions

- Change language.
- Review or tweak preferences.

## Implementation note

The settings screen now follows the shared dark surface vocabulary so the preference rows and avatar picker feel calmer and more consistent.
